# 🃏 Les trois cas : cartes de contraste

#flashcards/arabe/regles/1-cas/trois-cas

← [[Règles - paquets de cartes]] · Paquets détaillés : [[Cartes - Nominatif]] · [[Cartes - Accusatif]] · [[Cartes - Génitif]] · [[Cartes - Prépositions]] · Tableau : [[Tableau 2 - Les trois cas]]

> [!tip] Le fil rouge de ce paquet
> Ce paquet mélange les trois cas pour t'entraîner à **choisir**. À chaque carte, suis la même méthode :
> 1. Préposition juste avant ? → **-i**
> 2. Nom sans ال ni tanwīn juste avant (« le … de ») ? → **-i**
> 3. Sinon : sujet ou attribut → **-u** ; complément du verbe → **-a** ; après إِنَّ → **-a**.

## 1. Le tableau de base

Les trois cas : nom arabe, fin, et rôle principal ?
?
- **Nominatif** = rafʿ : **-u / -un** : sujet, attribut
- **Accusatif** = naṣb : **-a / -an** : complément d'objet
- **Génitif** = jarr : **-i / -in** : après préposition, « le X **de** Y »

Où se voit le cas d'un nom arabe ?
?
À la **dernière voyelle** du mot (ou à la terminaison ـُونَ / ـِينَ, ـَانِ / ـَيْنِ).
Le **sens** du mot ne change pas ; c'est son **rôle** dans la phrase qui change.

Les 3 questions à se poser, dans l'ordre, pour trouver le cas d'un nom ?
?
1. Y a-t-il une **préposition** juste avant ? → génitif (-i).
2. Le mot d'avant est-il un **nom sans ال ni tanwīn** ? → « le … de », génitif (-i).
3. Sinon, **que fait le mot ?** Sujet / attribut → nominatif (-u). Complément du verbe → accusatif (-a). Après إِنَّ → accusatif (-a).

Pourquoi l'ordre des mots est-il libre en arabe ?
?
Parce que les **cas** disent le rôle de chaque mot.
كَتَبَ الْوَلَدُ الدَّرْسَ = كَتَبَ الدَّرْسَ الْوَلَدُ = « l'enfant a écrit la leçon ».
Le -u montre le sujet, le -a montre le complément. L'ordre des mots peut changer, le sens reste.

## 2. Un même mot, trois rôles

Le mot الْبَيْت (la maison) : donne une phrase pour chaque cas.
?
- **الْبَيْتُ** كَبِيرٌ (-u) : « la maison est grande » : sujet.
- رَأَيْتُ **الْبَيْتَ** (-a) : « j'ai vu la maison » : complément.
- فِي **الْبَيْتِ** (-i) : « dans la maison » : après préposition.

Dans la Fatiha, trouve un exemple de chaque cas.
?
- **-u** : **الْحَمْدُ** لِلَّهِ : sujet de la phrase nominale.
- **-a** : اهْدِنَا **الصِّرَاطَ** : complément du verbe « guide ».
- **-i** : رَبِّ **الْعَالَمِينَ** ; مَالِكِ **يَوْمِ** الدِّينِ : « de ».

اللَّهُ / اللَّهَ / اللَّهِ : dans quelle phrase trouve-t-on chacun ?
?
- **اللَّهُ** أَكْبَرُ : sujet (-u).
- إِنَّ **اللَّهَ** غَفُورٌ : après إِنَّ (-a).
- بِسْمِ **اللَّهِ** ; **لِلَّهِ** : « de » ou après préposition (-i).

رَبُّ / رَبَّ / رَبِّ : trouve le cas.
1. رَبُّكَ الْأَكْرَمُ
2. اعْبُدُوا رَبَّكُمْ
3. الْحَمْدُ لِلَّهِ رَبِّ الْعَالَمِينَ
?
1. **رَبُّكَ** (-u) : sujet, « ton Seigneur est le Très-Noble ».
2. **رَبَّكُمْ** (-a) : complément, « adorez votre Seigneur ».
3. **رَبِّ** (-i) : il précise اللَّهِ, qui est au génitif après لِـ.

## 3. Analyse express

جَاءَ نَصْرُ اللَّهِ : donne le cas de chaque nom.
?
- **نَصْرُ** : nominatif (-u), sujet de جَاءَ.
- **اللَّهِ** : génitif (-i), « le secours **d'**Allah ».

خَلَقَ الْإِنْسَانَ مِنْ عَلَقٍ (96:2) : donne le cas de chaque nom.
?
« Il a créé l'homme d'une adhérence ».
- **الْإِنْسَانَ** : accusatif (-a), complément de خَلَقَ.
- **عَلَقٍ** : génitif (-in), après مِنْ.
(Le sujet « il » est caché dans le verbe.)

وَالْعَصْرِ إِنَّ الْإِنْسَانَ لَفِي خُسْرٍ : donne le cas de chaque nom.
?
- **الْعَصْرِ** : génitif (-i), après le وَ du serment (« Par le Temps ! »).
- **الْإِنْسَانَ** : accusatif (-a), après إِنَّ.
- **خُسْرٍ** : génitif (-in), après فِي.

يُحِبُّ اللَّهُ الْمُحْسِنِينَ : donne le cas de chaque nom.
?
« Allah aime les bienfaisants ».
- **اللَّهُ** : nominatif (-u), sujet.
- **الْمُحْسِنِينَ** : accusatif (ـِينَ), complément : Il aime **qui** ?

لَيْلَةُ الْقَدْرِ خَيْرٌ مِنْ أَلْفِ شَهْرٍ (97:3) : donne le cas de chaque nom.
?
« La nuit du Destin est meilleure que mille mois ».
- **لَيْلَةُ** : nominatif (-u), sujet.
- **الْقَدْرِ** : génitif (-i), « la nuit **du** Destin ».
- **خَيْرٌ** : nominatif (-un), attribut.
- **أَلْفِ** : génitif (-i), après مِنْ.
- **شَهْرٍ** : génitif (-in), « mille **de** mois ».

## 4. Les fins spéciales

Pluriel masculin : quelle forme pour quel cas ?
?
- **ـُونَ** : nominatif seulement (الْمُؤْمِنُونَ)
- **ـِينَ** : accusatif **et** génitif (الْمُؤْمِنِينَ)

Pluriel féminin en ـَات : quelle forme pour quel cas ?
?
- **-u / -un** : nominatif (الصَّالِحَاتُ)
- **-i / -in** : accusatif **et** génitif (الصَّالِحَاتِ). **Jamais -a.**

Diptote (ex. إِبْرَاهِيم) : quelle forme pour quel cas ?
?
- **-u** : nominatif (إِبْرَاهِيمُ)
- **-a** : accusatif **et** génitif (إِبْرَاهِيمَ). **Jamais -i ni tanwīn.**
(Il reprend -i s'il a ال ou s'il est le 1er mot d'une annexion.)

Quels mots **ne changent jamais** de fin ?
?
Les **pronoms** (هُوَ), les **démonstratifs** (هَذَا), les **relatifs** (الَّذِي), les **particules** (فِي, إِنَّ) et les **verbes au passé**.
On les dit **mabnī** (« bâtis »). Ils ont un rôle, mais aucune voyelle ne le montre.

Pourquoi n'entend-on pas les cas en fin de verset ?
?
À l'**arrêt** (waqf), la dernière voyelle tombe : الْعَالَمِينَ → *al-ʿālamīn* ; أَحَدٌ → *aḥad*.
Le cas reste **écrit**. Lis l'écrit, pas seulement l'oreille.
