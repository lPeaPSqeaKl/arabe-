# 🃏 Le passé (al-māḍī) : cartes

#flashcards/arabe/regles/3-verbe/passe

← [[Règles - paquets de cartes]] · Voir aussi : [[Cartes - Le présent]] · [[Cartes - Pronoms collés]] · Règle complète : Atelier arabe › Règles › « Le passé »

> [!tip] Le fil rouge de ce paquet
> Le passé = le verbe de base **فَعَلَ** (« **il** a fait ») + une **terminaison** pour la personne. La personne est **à la fin**.

Comment se forme le passé ?
?
1. On met la racine dans le moule **فَعَلَ** : كَتَبَ = **il** a écrit (forme du dictionnaire).
2. Pour une autre personne, on ajoute une **terminaison** : كَتَبْ + تُ = **كَتَبْتُ** (j'ai écrit).
Le sujet est dans la terminaison : pas besoin de « je ».

Terminaisons du passé : il / elle / tu (m.) / tu (f.) / je.
?
- il : **ـَ** كَتَبَ
- elle : **ـَتْ** كَتَبَتْ
- tu (homme) : **ـْتَ** كَتَبْتَ
- tu (femme) : **ـْتِ** كَتَبْتِ
- je : **ـْتُ** كَتَبْتُ

Terminaisons du passé : ils / vous / nous.
?
- ils : **ـُوا** كَتَبُوا (l'alif ne se prononce pas)
- vous : **ـْتُمْ** كَتَبْتُمْ
- nous : **ـْنَا** كَتَبْنَا

Que veulent dire كَتَبْنَا et كَتَبَتْ ?
?
**nous avons écrit** (-nā) ; **elle a écrit** (-at).

أَنْعَمْتَ (1:7) : quelle personne ?
?
**-ta** = « **tu** » : « (ceux que) **Tu** as comblés ».
Attention : -ta (tu, homme), -ti (tu, femme), -tu (je) : seule la dernière voyelle change.

أَعْطَيْنَاكَ : décompose.
?
أَعْطَيْ + **نَا** (sujet : **nous**) + **كَ** (complément : **toi**).
« **Nous t'**avons donné. »

قَالَ (il a dit) → « j'ai dit » ?
?
**قُلْتُ** (*qultu*). La racine est ق و ل : le ā de قَالَ **raccourcit** en u devant -tu.
Même chose : كَانَ → كُنْتُ (j'étais).

إِذَا جَاءَ نَصْرُ اللَّهِ : pourquoi traduit-on au futur ?
?
Après **إِذَا** (quand) ou **إِنْ** (si), un verbe au passé se traduit souvent au **présent ou futur** : « **quand viendra** le secours d'Allah ».

قَالَ النَّاسُ ou قَالُوا النَّاسُ ?
?
**قَالَ النَّاسُ**. Quand le sujet nommé est **après**, le verbe reste au **singulier**.
