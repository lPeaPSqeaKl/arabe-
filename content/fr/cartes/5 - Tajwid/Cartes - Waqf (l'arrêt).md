# 🃏 Le waqf (l'arrêt) : cartes

#flashcards/arabe/regles/5-tajwid/waqf

← [[Règles - paquets de cartes]] · Voir aussi : [[Cartes - Le tanwin]] · [[Cartes - Le ta marbouta]] · Règle complète : Atelier arabe › Règles › « Le waqf »

Que se passe-t-il quand on **s'arrête** sur un mot ?
?
Sa **dernière voyelle** ne se prononce pas : on finit sur une consonne (soukoun).
الْعَالَمِينَ → *al-ʿālamīn*.

À l'arrêt, que deviennent : -u / -a / -i ; -un / -in ; -an ?
?
- -u, -a, -i : **tombent** : الْكَوْثَرَ → *al-kawthar*
- -un, -in : **tombent** : أَحَدٌ → *aḥad*
- -an : devient **ā** : تَوَّابًا → *tawwābā*

À l'arrêt, que devient ة ?
?
**h** : الْقَارِعَةُ → *al-qāriʿah*.

À l'arrêt, que devient une voyelle **longue** finale ?
?
Elle **reste** : الْأَعْلَى → *al-aʿlā*.

Comment dit-on الْقَدْرِ (97:1) en s'arrêtant ?
?
*al-qadr* : le -i final tombe.

Pourquoi le waqf compte-t-il pour la grammaire ?
?
Les terminaisons de **cas** disparaissent à l'arrêt. Pour connaître le cas d'un mot en fin de verset, il faut regarder l'**écrit**.

Signes d'arrêt : مـ / لا / ج ?
?
- **مـ** : arrêt **obligatoire** (sinon le sens change)
- **لا** : **ne pas** s'arrêter ici
- **ج** : arrêt **permis**

Tu dois respirer au mauvais endroit : que fais-tu ?
?
Tu **reprends un ou deux mots avant**, pour ne pas couper le sens.
