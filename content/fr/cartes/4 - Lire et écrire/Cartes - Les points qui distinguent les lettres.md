# 🃏 Les points qui distinguent les lettres : cartes

#flashcards/arabe/regles/4-lecture/points

← [[Règles - paquets de cartes]] · Règle : [[Les points qui distinguent les lettres]]

Qu'est-ce qui distingue ب ت ث ن ?
?
Seulement les **points** : ب 1 dessous, ت 2 dessus, ث 3 dessus, ن 1 dessus. Même forme de « barque ».
(Au début et au milieu, ي a aussi cette forme, avec 2 points dessous.)

Qu'est-ce qui distingue ج ح خ ?
?
ج : 1 point **dedans/dessous** ; ح : **aucun** point ; خ : 1 point **dessus**.

Les paires qui ne diffèrent que d'un point : د / ? ; ر / ? ; س / ? ; ص / ?
?
- د / **ذ** (d / dh)
- ر / **ز** (r / z)
- س / **ش** (s / sh, 3 points)
- ص / **ض** (ṣ / ḍ)

Les paires qui ne diffèrent que d'un point : ط / ? ; ع / ? ; ف / ?
?
- ط / **ظ** (ṭ / ẓ)
- ع / **غ** (ʿ / gh)
- ف (1 point) / **ق** (2 points)

Quand ajoute-t-on les points en écrivant ?
?
On trace d'abord **tout le mot**, puis on ajoute **les points** à la fin.
