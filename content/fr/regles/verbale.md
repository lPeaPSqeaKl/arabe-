## En bref
Une **phrase verbale** commence par un **verbe**. L'ordre habituel est : **verbe → sujet (-u) → complément (-a)**.

## Pas à pas
Construisons « l'enfant a écrit la leçon » :
1. Le verbe : **كَتَبَ** (il a écrit).
2. Le sujet, au nominatif : **ٱلْوَلَدُ** (l'enfant).
3. Le complément, à l'accusatif : **ٱلدَّرْسَ** (la leçon).
4. Ensemble : **كَتَبَ ٱلْوَلَدُ ٱلدَّرْسَ** = a écrit l'enfant la leçon.

## L'ordre peut changer
Grâce aux cas, on peut déplacer les mots : كَتَبَ ٱلدَّرْسَ ٱلْوَلَدُ veut dire la même chose. Le **-u** dit qui est le sujet, le **-a** dit qui est le complément. Mettre un mot en avant sert à **insister** : إِيَّاكَ نَعْبُدُ = c'est **Toi** que nous adorons.

## L'accord du verbe
- Quand le verbe est **avant** le sujet, il reste **au singulier** (il s'accorde seulement en genre) : جَاءَ ٱلرِّجَالُ (les hommes sont venus), جَاءَتِ ٱلنِّسَاءُ (les femmes sont venues).
- Quand le sujet est **avant** le verbe, le verbe s'accorde complètement : ٱلرِّجَالُ جَاءُوا.

## Le sujet caché
Si le sujet est un pronom (je, tu, nous…), il n'y a pas de mot séparé : il est **dans la terminaison** du verbe. خَلَقْنَا = **nous** avons créé. رَأَيْتَ = **tu** as vu.

## Dans le Coran
@coran 110:1 | 2,3 | جَآءَ نَصْرُ ٱللَّهِ : verbe + sujet au nominatif.
@coran 99:2 | 1,2,3 | وَأَخْرَجَتِ ٱلْأَرْضُ أَثْقَالَهَا : verbe + sujet (-u) + complément (-a). Le verbe est au féminin, comme ٱلْأَرْض.
@coran 105:1 | 4,5 | فَعَلَ رَبُّكَ : « ton Seigneur a agi ».
@coran 1:5 | 1,2 | إِيَّاكَ نَعْبُدُ : complément placé **avant** le verbe pour insister.

## Les pièges
- Le verbe ne s'accorde pas en nombre avec un sujet placé après : ne pas écrire جَاءُوا ٱلرِّجَالُ.
- Un nom placé avant le verbe transforme la phrase en phrase nominale (le nom devient sujet, la phrase verbale devient son attribut).

## Comparaison avec le russe
L'ordre libre est le même qu'en russe : « Мальчик написал урок » = « Урок написал мальчик ». Ce sont les terminaisons qui décident.

## Pour vérifier
> Dans أَكَلَ ٱلتُّفَّاحَةَ ٱلْوَلَدُ, qui a mangé quoi ?
> Réponse : **l'enfant** (ٱلْوَلَدُ, -u) a mangé **la pomme** (ٱلتُّفَّاحَةَ, -a).
