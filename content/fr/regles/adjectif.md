## En bref
L'**adjectif** (naʿt, النَّعْت) se place **après** le nom et le **copie** en tout : même cas, même ال ou même tanwīn, même genre, même nombre.

## Les quatre accords
1. **Le cas** : nom à -u → adjectif à -u ; nom à -i → adjectif à -i.
2. **Défini / indéfini** : nom avec ال → adjectif avec ال ; nom avec tanwīn → adjectif avec tanwīn.
3. **Le genre** : nom féminin → adjectif avec **ـة** (كَبِيرَة).
4. **Le nombre** : singulier, duel ou pluriel. Mais un **pluriel de choses** se traite comme un **féminin singulier** : بُيُوتٌ كَبِيرَةٌ (de grandes maisons).

| Groupe | Lecture | Sens |
|---|---|---|
| بَيْتٌ كَبِيرٌ | baytun kabīrun | une grande maison |
| ٱلْبَيْتُ ٱلْكَبِيرُ | al-baytu l-kabīru | la grande maison |
| فِي ٱلْبَيْتِ ٱلْكَبِيرِ | fi l-bayti l-kabīri | dans la grande maison |
| مَدْرَسَةٌ كَبِيرَةٌ | madrasatun kabīratun | une grande école |

## Adjectif ou phrase ?
C'est la question la plus importante :
- **défini + défini** (ٱلْبَيْتُ ٱلْكَبِيرُ) = un **groupe** : « la grande maison » ;
- **défini + indéfini** (ٱلْبَيْتُ كَبِيرٌ) = une **phrase** : « la maison **est** grande ».
Le ال (ou son absence) sur le deuxième mot fait toute la différence.

## Dans le Coran
@coran 1:6 | 2,3 | ٱلصِّرَٰطَ ٱلْمُسْتَقِيمَ : « le chemin droit », deux accusatifs avec ال.
@coran 1:1 | 2,3,4 | ٱللَّهِ ٱلرَّحْمَٰنِ ٱلرَّحِيمِ : deux adjectifs qui copient le génitif de ٱللَّه.
@coran 2:7 | 11,12 | عَذَابٌ عَظِيمٌ : « un châtiment immense », deux nominatifs indéfinis.
@coran 89:27 | 2,3 | ٱلنَّفْسُ ٱلْمُطْمَئِنَّةُ : « l'âme apaisée », féminin (ـة) comme نَفْس.

## Plusieurs adjectifs
On peut en mettre plusieurs à la suite : ils copient tous le **même** nom. ٱلْعَلِيُّ ٱلْعَظِيمُ (le Très-Haut, l'Immense).

## Avec une annexion
L'adjectif se met **après tout le groupe**, et il copie le mot qu'il qualifie : بَيْتُ ٱللَّهِ ٱلْحَرَامُ — ٱلْحَرَامُ qualifie بَيْت (la Maison sacrée), donc il prend le -u de بَيْت.

## Les pièges
- Un nom avec un possessif est défini : son adjectif prend ال. رَبُّكَ ٱلْأَكْرَمُ = ton Seigneur le Très-Noble.
- Les pluriels de personnes gardent un adjectif pluriel : رِجَالٌ صَالِحُونَ (des hommes vertueux).

## Pour vérifier
> ٱلرَّجُلُ صَالِحٌ ou ٱلرَّجُلُ ٱلصَّالِحُ : lequel veut dire « l'homme vertueux » ?
> Réponse : **ٱلرَّجُلُ ٱلصَّالِحُ** (défini + défini). L'autre veut dire « l'homme est vertueux ».
